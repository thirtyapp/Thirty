# THIRTY Wordmark

**Version:** v1.0
**Status:** Approved v1.0. Approval covers the wordmark **direction** only (§1–§10) — it does not approve a final font, final letter geometry, final proportions, final tracking, final weight, a specific visual concept, a production master vector wordmark asset, exact First Breath dimensions, exact animation timing, or Flutter/SVG integration. Those remain separate, later approvals (§13, Approval Pipeline, stages 3–6). It does not itself authorise any image, font selection, or code asset (§12, Non-Goals).

## Purpose

This document defines the direction for the THIRTY wordmark: the stable, uppercase "THIRTY" brand identifier, and the reason it — not a standalone symbol — is now the brand moment inside The First Breath.

It exists because [THIRTY_SYMBOL.md v2.0](THIRTY_SYMBOL.md#status-update--first-breath-is-now-wordmark-led-v20) records an explicit direction change: repeated visual exploration toward a standalone symbol for First Breath produced only generic wellness imagery, sports and performance geometry, interface-symbol associations, or gestures too weak to work without a wordmark alongside them — while the existing THIRTY wordmark consistently read as the strongest, calmest, most credible brand presence across that same exploration. First Breath is therefore wordmark-led. A standalone symbol is no longer required for it and is no longer a prerequisite for First Breath v2.

The wordmark serves:

- the stable THIRTY brand identifier, wherever one is needed;
- the First Breath brand moment specifically (§2 below);
- wider future brand contexts (app store listing, website, social avatar — not decided here, see §12);
- a role distinct from the Circle, restated in §5.

**Formal rule, inherited unchanged from the authority this document builds on:**

> "The Circle is not the logo. The Circle is the product." — [Playbook Ch.1 §3](../playbook/01-the-circle-manifesto.md#3-the-meaning-of-the-circle)

The wordmark is the "logo" that sentence refers to. Naming it explicitly does not change what the sentence has always meant: the wordmark represents THIRTY as a brand; the Circle remains the product it never competes with.

## 2. Canonical First Breath Use

**Decision: wordmark only. No standalone symbol beside it, no combined lock-up.**

- The wordmark appears alone inside the closed Circle at steps 2–4 of the canonical sequence (§4; [World System §13](../worlds/WORLD_SYSTEM.md#13-first-breath-relationship)).
- No standalone THIRTY symbol appears alongside or behind it — [THIRTY_SYMBOL.md](THIRTY_SYMBOL.md) is superseded for this use (v2.0).
- No combined lock-up (wordmark plus symbol together) is used inside the Circle. A future standalone symbol, if one is ever approved, would need its own separate decision about whether it ever appears alongside the wordmark anywhere — that question is not opened here, and nothing in this document assumes an answer to it.
- No surrounding plate, badge, or frame behind the wordmark.
- No background asset behind the wordmark — it sits directly on the Circle's interior, which is the app's existing background colour showing through, not a separate rendered surface.
- No decorative atmosphere (glow, light, texture, gradient) baked into the wordmark asset itself. Future ambient atmosphere around it, if any is ever explored, is a separate decision from the mark asset — the same discipline [THIRTY_SYMBOL.md §5](THIRTY_SYMBOL.md#5-colour) already established for the symbol.

This is a narrower decision than "the wordmark exists" — it is specifically that the First Breath brand moment is the wordmark, unaccompanied, and nothing else.

## 3. Typographic Direction

This section decides direction, not a typeface. No final font is selected here (§12).

**The wordmark is:**

- set in **uppercase** — "THIRTY," not "Thirty" or "thirty";
- **calm** — it introduces the ritual and steps aside; it does not perform;
- **humanist** — warmth in the letterforms, not a geometric-grotesque rigidity;
- **highly legible** — this is a brand identifier read in a few seconds at mobile size, not a display headline read at leisure;
- **warm** — consistent with THIRTY's Cream/Circle-Sage palette and "calm, capable friend" personality ([Brand Book §7](../BRAND_BOOK.md#7-personality));
- **editorial** — the same quality [World System §6](../worlds/WORLD_SYSTEM.md#6-illustration-language) already asks of World illustration, applied to type: considered, not manufactured;
- **timeless** — a ten-year test, the same standard [Playbook Ch.4 §9, the Longevity Filter](../playbook/04-product-decision-framework.md#9-the-longevity-filter) already applies to every other design decision;
- **restrained** — no unnecessary flourish; every letterform choice should be explainable, the same bar [THIRTY_SYMBOL.md §3](THIRTY_SYMBOL.md#3-form-principles) set for the symbol ("every stroke should be explainable");
- **suitable at mobile size** — legible at the scale the current Circle Hero actually renders it (§6), not only at a large design-review size.

**Reject:**

| Rejected direction | Reason |
|---|---|
| Athletic typography | Reads as a fitness-app identity — exactly what [DESIGN_SYSTEM.md §1](../DESIGN_SYSTEM.md#1-why-the-palette-changed) already moved THIRTY away from ("energetic, technological... a fitness-app palette, not a calm daily ritual"), now stated for type. |
| Futuristic typography | Signals novelty and technology over calm and timelessness — fails the Longevity Filter on sight. |
| Condensed sports lettering | The same athletic failure, compounded by legibility loss at small size. |
| Luxury-fashion serif styling | Signals status and exclusivity, not the "calm, capable friend" [Brand Book §7](../BRAND_BOOK.md#7-personality) describes; wrong emotional register entirely. |
| Script | Fails legibility at mobile size outright, and reads as decorative rather than considered. |
| Distressed lettering | Signals ruggedness or nostalgia — neither is a THIRTY quality. |
| Playful children's typography | THIRTY motivates without guilt, but it is not playful or juvenile — see [Brand Book, Personality](../BRAND_BOOK.md#7-personality) generally. |
| Heavy corporate boldness | Reads as assertive and performative — the opposite of "the brand introduces the ritual, then steps aside" ([World System §13](../worlds/WORLD_SYSTEM.md#13-first-breath-relationship)). |
| Exaggerated custom quirks | A quirky letterform draws attention to its own craftsmanship — precisely what [Motion Language §2](../motion/MOTION_LANGUAGE.md#2-design-principles) already warns against for movement ("a movement that draws attention to its own craftsmanship has drawn attention away from what it was meant to support"), applied here to type. |

No final font, weight, tracking value, or letter geometry is selected by this document (§12).

## 4. Motion Relationship

**Canonical First Breath sequence** (full sequence at [World System §13](../worlds/WORLD_SYSTEM.md#13-first-breath-relationship)):

1. The closed Circle is present.
2. The stable THIRTY wordmark appears inside it.
3. The wordmark remains briefly and completely still.
4. The wordmark fades out completely.
5. The Circle opens.
6. The selected World appears.
7. Home content follows through the existing reveal hierarchy.

**The wordmark receives no heartbeat scale animation.** This is a deliberate departure from [THIRTY_SYMBOL.md §6](THIRTY_SYMBOL.md#6-motion-compatibility)'s heartbeat, not an oversight:

- a horizontal wordmark depends on stable letterforms for clarity — any scale change risks a moment of blur or misregistration that a small abstract mark does not risk in the same way;
- a scale heartbeat on legible text risks reading as performative ("look at me") rather than present — exactly the failure mode [Motion Language §2](../motion/MOTION_LANGUAGE.md#2-design-principles) warns motion against generally;
- the brand moment should communicate presence through stillness, not through movement — consistent with [Motion Language §13, Silence](../motion/MOTION_LANGUAGE.md#13-silence): "stillness is part of the experience";
- the Circle opening remains the ritual's principal lifecycle motion (step 5) — the wordmark's job is to be present and then recede, not to compete with that motion for attention;
- stillness preserves [Motion Language §5](../motion/MOTION_LANGUAGE.md#5-motion-budget)'s "one Primary Motion at a time" cleanly: the wordmark's appear/hold/fade is a single, quiet beat, not a second animated event racing the Circle's opening.

**Compliance with Motion Language, confirmed:**

- one Primary Motion at a time (§5) — the wordmark's appear-hold-fade is one beat; Circle Opening is the next;
- no bounce, spring, elastic, or overshoot (§7) — the wordmark only fades in, holds, and fades out;
- no First Breath haptic — haptics remain reserved for Start Circle and Circle Closed only ([Motion Language §10](../motion/MOTION_LANGUAGE.md#10-haptics); [World System §13](../worlds/WORLD_SYSTEM.md#13-first-breath-relationship));
- no hurry — the sequence belongs to the Ceremonial timing category ([Motion Language §6](../motion/MOTION_LANGUAGE.md#6-timing));
- stillness respected — the wordmark's defining motion property is that, for most of its appearance, it does not move at all.

This document sets no numeric duration, opacity curve, or easing value — those belong to a later motion implementation and tuning pass (§12), checked against [Motion Language §6](../motion/MOTION_LANGUAGE.md#6-timing)'s Ceremonial category and this document's qualitative requirements.

**Reduced motion** remains mandatory in the First Breath v2 implementation sprint — this requirement is unchanged from [THIRTY_SYMBOL.md §12](THIRTY_SYMBOL.md#12-reduced-motion), restated here for the wordmark:

1. The closed Circle is present.
2. The stable THIRTY wordmark appears without scale animation (it never had one — §4 above — so this step differs from the normal-motion path only in what follows it).
3. The wordmark remains briefly stable.
4. It disappears through a very brief, calm crossfade or an immediate transition.
5. The Circle moves directly or near-directly to its open, settled state.
6. The selected World and Home content become available without the normal long stagger.
7. Start Circle interaction is not unnecessarily delayed.

**This reduced-motion path preserves:**

- the same daily ritual meaning — the wordmark still marks the day's opening; nothing is silently removed, only shortened;
- the same local-calendar, once-per-day persistence ([`first_breath_provider.dart`](../../lib/features/home/application/first_breath_provider.dart));
- the same selected World;
- the same accessibility semantics (§8) — still decorative, still a single Circle semantics owner;
- the same free/Premium boundary (§9) — reduced motion is a platform/user setting, never a Premium differentiator in either direction.

**This document does not prescribe** exact durations, Flutter APIs, `MediaQuery` implementation details, or animation-controller architecture. Those are implementation decisions for the later technical pass (§12, §13), checked against this specification rather than decided here.

**Reduced motion reduces movement and waiting — never meaning or access.** Every step above still happens; only how long each one takes, and how much it visibly animates, is reduced.

## 5. Relationship to the Circle

The wordmark sits inside the closed Circle, clearly subordinate to it — adapted directly from [THIRTY_SYMBOL.md §4](THIRTY_SYMBOL.md#4-relationship-to-the-circle)'s unrejected relationship principles:

- horizontally centred;
- optically centred (accounting for the visual weight of uppercase Latin letterforms, which is not always identical to their geometric bounding box);
- generous inset from the Circle's stroke — it must not touch the stroke, and must read with visible breathing room on every side, not merely clear the stroke by the smallest safe margin;
- clearly subordinate to the Circle — a small, quiet mark resting inside a large, calm space, never a second focal point;
- no curved baseline following the Circle's arc — the wordmark sets on a straight, horizontal baseline;
- no circular lock-up of any kind;
- no distortion — no stretching, compressing, or perspective applied to fit the available space;
- no wrapping around the Circle;
- no change to the Circle's geometry to accommodate it.

**The Circle does not resize or reshape around the wordmark.** The relationship is a small mark resting inside a large, unchanged space — never the reverse. This is the same rule [THIRTY_SYMBOL.md §4](THIRTY_SYMBOL.md#4-relationship-to-the-circle) already established for the symbol, restated here because it does not change with the mark that occupies the space.

No exact pixel dimensions are defined here (§12) — §6 assesses feasibility against the Circle's actual current dimensions without fixing final numbers.

## 6. Current-Size Feasibility

This section assesses feasibility against the real implementation, not a placeholder. It decides nothing about final typography — a production asset remains a required, separate approval before implementation (§13).

**What the Circle Hero actually does today** ([`circle_hero.dart`](../../lib/features/home/presentation/widgets/circle_hero.dart)):

- The Circle's diameter (`circleSize`) is derived from available width, not a fixed constant: `(constraints.maxWidth * 0.88).clamp(_circleMinSize, safeMaxSize)`, where `_circleMinSize = 260.0` and `_circleMaxSize = 440.0`, and `safeMaxSize` additionally caps the Circle below `constraints.maxWidth − AppSpacing.page × 2` so it is never clipped by the page's own margins.
- Stroke width (`_circleStrokeWidth`) is `12.0`.
- The interior content region — where the World illustration renders today, and where the wordmark would render during First Breath — is `circleSize − (strokeWidth × 2)`: **236px at the documented floor (260px Circle), up to 416px at the documented ceiling (440px Circle)**.
- No symbol- or wordmark-rendering step exists in the codebase today — First Breath v1, as currently implemented, goes directly from the closed-Circle release straight into the World illustration and content reveal. First Breath v2 (the wordmark-led ritual this document describes) is not yet built, consistent with this task's non-goals (§12).

**Assessment.** [THIRTY_SYMBOL.md §4](THIRTY_SYMBOL.md#4-relationship-to-the-circle) required the symbol to sit with "materially more inset" than the illustration, which fills nearly the full interior region. The same discipline applies to the wordmark, which means its usable safe width is meaningfully smaller than the full 236–416px interior range above — likely on the order of half to two-thirds of it, to preserve visible breathing room on every side rather than merely clearing the stroke.

At the Circle's typical rendered size on most phones (comfortably above the 260px floor for a portrait phone screen at the 88% width fraction), an uppercase six-letter wordmark set at a modest, brand-appropriate size with generous tracking should read as calm, legible, and clearly subordinate to the Circle — nothing about the geometry rules this out.

**Genuine constraints, real rather than hypothetical:**

- **The documented floor is the binding case.** At `_circleMinSize = 260`, the interior region is only 236px — narrow enough that a wordmark with generous, brand-appropriate letter-spacing must be verified specifically at this floor, not assumed safe because it fits comfortably at a typical or maximum Circle size. This floor is reached on genuinely narrow layouts, not only in theory: a narrow phone, a split-screen or multi-window layout, or a foldable's inner display can all push `constraints.maxWidth` down to where the floor, not the 88%-of-width case, governs.
- **Landscape and narrow layouts** push toward the same floor for a different reason: `safeMaxSize` is also capped by `constraints.maxWidth − AppSpacing.page × 2`, so a wide-but-short (landscape) viewport does not help — the Circle's size is bounded by width, and a narrow width is a narrow width regardless of orientation.
- **Letter-spacing is a direct trade-off against the floor.** The "editorial, warm, restrained" typographic direction (§3) implies generous tracking, which widens the rendered wordmark for a given point size — the final tracking value chosen must be checked against the floor case specifically, not only against a comfortable mid-range Circle size.
- **System text-scaling (accessibility) is an open, unresolved risk, not a solved one.** THIRTY's typography today (`app_typography.dart`) defines fixed point sizes with no stated policy on capping `MediaQuery` text-scale for brand-identity elements. If the wordmark is implemented as ordinary scalable text, a user with a large system text-scale setting could see it grow enough, at the 260px floor, to threaten "no contact with the Circle stroke" and the generous-inset requirement (§5). This needs an explicit implementation decision — most commonly, exempting a brand wordmark from user text-scaling, as is conventional for logotypes — which is not decided here and remains open for the implementation pass (§12, §13).
- **Stroke weight** (12px) is already accounted for in the interior-region math above; it does not introduce a separate risk beyond narrowing the available space, but the wordmark's inset must be measured from the interior boundary (`circleSize − strokeWidth × 2`), the same boundary the illustration is inset to today — not from the Circle's nominal outer size.

**Conclusion.** An uppercase THIRTY wordmark is feasible within the Circle Hero's actual current dimensions at typical and larger rendered sizes. At the documented minimum Circle size, and under large system text-scale settings, feasibility is genuinely tighter and depends on choices not yet made (exact typeface, tracking, and a text-scale policy) — these are real constraints to verify against the eventual production asset (§13), not reasons to doubt the wordmark-led direction itself. A production asset remains required before implementation regardless of this assessment.

## 7. Colour

The wordmark inherits the canonical Design System identity token — **Circle Sage** (`#7C8B6D`, per [DESIGN_SYSTEM.md §2.1](../DESIGN_SYSTEM.md#brand-identity-vs-implementation-tokens)) — exactly as [THIRTY_SYMBOL.md §5](THIRTY_SYMBOL.md#5-colour) already established for the symbol. DESIGN_SYSTEM.md remains the sole authority for the token's value; this document does not define, own, or duplicate it, and introduces no new token.

**The wordmark must:**

- work in monochrome, using Circle Sage as its single colour;
- remain legible against THIRTY's warm neutral background — Cream in light mode, the derived dark near-black background in dark mode ([DESIGN_SYSTEM.md §2.4](../DESIGN_SYSTEM.md), §3);
- remain identical across every World;
- remain identical for free and Premium users (§9).

**The wordmark must not:**

- use gradients;
- use shadows or glow;
- carry texture or baked-in atmosphere of any kind;
- vary by World colour;
- vary by season or daypart;
- vary by Premium status.

## 8. Accessibility

**Decision: the wordmark is decorative during First Breath**, exactly as [THIRTY_SYMBOL.md §11](THIRTY_SYMBOL.md#11-accessibility) already decided for the symbol, restated here because it does not change with the mark that occupies the space.

- The Circle already exposes the only meaningful semantics for this moment, via `ThirtyProgressCircle`'s existing `Semantics` node ("Today's Circle" / "Ready to begin.", [`circle_hero.dart`](../../lib/features/home/presentation/widgets/circle_hero.dart)).
- Rendering "THIRTY" as visible text during First Breath does not, on its own, require a second announcement: a screen-reader user already knows which app they opened before First Breath plays — the platform announces the app on launch — so a mid-ritual repetition of the app's name is redundant, not informative.
- This matches the existing precedent `circle_hero.dart` already sets for the World illustration layer, wrapped in `ExcludeSemantics` for the same reason: a single meaningful Circle semantics owner, not a second, competing one. The wordmark should be excluded from semantics the same way when implemented.
- Opacity or transition progress is not narrated.
- Hidden World content does not create duplicate semantics.
- Reduced motion (§4) preserves access to all content — it changes timing and movement, never meaning.
- Start Circle is not actionable before it is ready, unchanged from the existing implementation (`IgnorePointer` gated on the button's own reveal animation in `circle_hero.dart`).

**One difference from the symbol's accessibility case, worth naming explicitly:** a wordmark renders literal text. Rendering it as an actual `Text` widget (rather than, say, an image containing the word) means it is not at risk of becoming an unlabeled "image of text" — a screen-reader concern [THIRTY_SYMBOL.md §2](THIRTY_SYMBOL.md#2-symbol-versus-wordmark) named as an argument for the (then-approved) symbol. Excluding it from semantics via `ExcludeSemantics`, as above, is what keeps it decorative regardless of which rendering approach (text vs. vector asset) implementation eventually chooses — that choice is not made here (§12).

No spoken animation narration is added by this document.

## 9. Free and Premium Boundary

- The complete wordmark-led First Breath ritual is free, per [PREMIUM_STRATEGY.md §1](../product/PREMIUM_STRATEGY.md#1-free-product-promise) ("The First Breath, in full") and [ADR-007](../product/adr/ADR-007-premium-never-blocks-the-core-loop.md).
- Premium does not receive a different wordmark.
- Premium does not receive a longer brand moment.
- Premium does not receive additional wordmark motion.
- Cancellation never changes the wordmark — a returning free user sees exactly the same wordmark they always did, per [PREMIUM_STRATEGY.md §8](../product/PREMIUM_STRATEGY.md#8-personal-growth-and-premium)'s standing rule that a cancelled subscription returns a user to the free experience, not a diminished one.
- No entitlement logic belongs in the brand ritual.

Future Premium Atmosphere ([PREMIUM_STRATEGY.md §7](../product/PREMIUM_STRATEGY.md#7-premium-atmosphere)) may enrich the selected World only after the shared brand moment and Circle opening have completed — never the wordmark phase itself, and never in a way that makes the ritual different for a paying user.

## 10. Multiple-World Independence

The wordmark and its ritual know nothing about:

- Quiet Trail;
- `ActivityCategory`;
- World;
- Place;
- season;
- daypart;
- weather;
- Personal Growth;
- Premium Atmosphere.

The reusable conceptual sequence:

> Wordmark brand moment → Circle opening → selected World reveal

Every future Circle Hero World reuses the same wordmark-led ritual unchanged. Nothing about the wordmark's form, colour, or motion is parameterised by which World, season, or Premium state follows it.

## 11. Review Checklist

Before any First Breath wordmark asset ships, it should be able to answer these honestly:

- Does the wordmark remain distinct from the Circle?
- Is it readable at mobile size, including at the Circle's documented minimum size (§6)?
- Does it feel calm rather than performative?
- Does it hold completely still before fading?
- Is it visually subordinate to the Circle?
- Does it work in monochrome, using Circle Sage only?
- Does it remain identical across every World?
- Does it remain identical for free and Premium users?
- Does reduced motion preserve the ritual without unnecessary animation?
- Does it avoid every rejected typographic direction in §3?

A wordmark that cannot be answered well on all of these is not ready, regardless of how well it is set.

### Approval Pipeline

This document is **Approved (v1.0)**. Reaching Approved status promotes the wordmark *direction* only (§1–§10) — it does not itself contain, imply, or approve any final geometry, typography, or artwork (§12). The full pipeline from here to an implemented First Breath v2:

1. **Approve the wordmark-led First Breath decision** — complete. Recorded in [THIRTY_SYMBOL.md v2.0](THIRTY_SYMBOL.md#status-update--first-breath-is-now-wordmark-led-v20).
2. **Approve this wordmark direction document** — complete through this task. This document is Approved (v1.0), per [GOVERNANCE.md's approval workflow](../playbook/GOVERNANCE.md#approval-workflow).
3. **Create multiple wordmark-only visual concepts** — not started. A future, separate design pass, checked against §3's typographic direction and rejection list. None exists yet. Earlier exploratory symbol, gesture, and lock-up concepts considered before the wordmark-led decision were rejected and are not repository assets — they do not count toward this stage, which begins from nothing.
4. **Select and refine one wordmark** — not started. A deliberate narrowing from several candidates to one, checked against the full specification (§3–§7).
5. **Approve the production master vector wordmark asset** — not started. The specific, final file is reviewed and approved on its own, separately from the direction that shaped it.
6. **Implement First Breath v2** — not started. A Flutter implementation task builds both the normal-motion and reduced-motion (§4) paths from the approved asset and this specification, checked against them rather than redefining either.

Each stage requires its own explicit approval; none is skipped by completing an earlier one. This task completes stage 2. No stage past 2 is authorised by anything in this document — approval of direction does not authorise any font, geometry, asset, or code.
