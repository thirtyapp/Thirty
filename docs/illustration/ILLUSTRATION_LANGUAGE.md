# THIRTY Illustration Language

**Version:** v1.0
**Status:** Approved v1.0

## Purpose

Define the artistic language used to illustrate every World inside THIRTY.

This document governs style. It does not govern content.

*What a World shows* — which Places exist, whether a figure may appear, which colour tokens are available, how a World grows over time — is governed by [WORLD_SYSTEM.md](../worlds/WORLD_SYSTEM.md) and [DESIGN_SYSTEM.md](../DESIGN_SYSTEM.md). *How anything THIRTY illustrates is drawn* — its line, its colour behaviour, its composition, its restraint — is governed here.

## 1. Core Philosophy

THIRTY illustrates places, not objects.

A tree exists because the place needs a tree. A bird exists because the atmosphere needs life. Neither exists because a tree, or a bird, is an interesting thing to draw on its own. The moment an illustration starts being *about* the tree — its species, its silhouette, its cleverness as a piece of drawing — it has stopped being a World and started being an object with a World-shaped backdrop.

This is not a stylistic preference. It is the same instinct World System §1 already states for Worlds as a whole: the test for whether an illustration is doing its job is a feeling, not a checklist — *"I would like to be there,"* never *"that is a nice icon."* An object illustration asks to be admired. A place asks to be entered. THIRTY only wants the second reaction.

The goal is never object illustration. The goal is emotional atmosphere — the same atmosphere World System §1 describes an illustrated World as existing to create before a single word of a recommendation is read, and the same reduction Playbook [Chapter 3 §2, Visual Philosophy](../playbook/03-circle-design-language.md#2-visual-philosophy) already asks of every visual decision in THIRTY: *"the measure of a good screen... is not what was added to make it appealing, it's what could be safely removed without losing meaning."* Applied to illustration, that means every mark should be answerable to the atmosphere it serves, not to its own craft.

> **Formal principle: Atmosphere before detail.**

When a decision has to be made between a more accurate, more detailed rendering of one element and a quieter, more atmospheric one, the quieter version wins — the same way Playbook Chapter 4's Calm Filter already resolves every other close call in THIRTY: *"when unsure, choose the version with less in it."*

## 2. Design Principles

These are the standing qualities every THIRTY illustration is checked against. None of them is new — each names, at illustration scale, a principle Chapters 1–3 of the Playbook or World System §6 already established for the product as a whole.

**Editorial.** THIRTY's illustrations should read the way a considered magazine or book illustration reads — composed, purposeful, made by a hand with a point of view — never like interface iconography that happens to be larger. This is named directly in World System §6.

**Quiet.** An illustration should never ask to be looked at before the Circle does (Playbook [Chapter 3 §3](../playbook/03-circle-design-language.md#3-the-circle)). It recedes into the feeling of the screen the same way Chapter 2's audio silence recedes into the feeling of a moment — present, never performing.

**Organic.** Nothing in a THIRTY illustration should look like it was built from primitive shapes. Trees, hills, and paths should carry the irregularity of things that grew, not the regularity of things that were constructed — World System §6's explicit instruction to favour "natural rather than geometric" forms.

**Restrained.** One accent used with intention says more than several used freely — the illustration-scale expression of Playbook [Chapter 3 §6](../playbook/03-circle-design-language.md#6-color-philosophy): *"A narrow, consistent [palette] signals that a product already trusts what it's built."*

**Timeless.** An illustration should still feel correct in ten years, the same standard Playbook [Chapter 4 §9, The Longevity Filter](../playbook/04-product-decision-framework.md#9-the-longevity-filter), already applies to every other product decision. A style that depends on this year's illustration trend has borrowed against a debt it will eventually have to pay.

**Human.** No THIRTY World shows a person (World System §2) — but the *hand* behind the illustration should still be felt. This is the illustration equivalent of Brand Book [§17](../BRAND_BOOK.md#17-photography-style)'s insistence on real, unperformed moments over polished production: a line with natural variation reads as made by someone; a perfectly uniform line reads as generated by something.

**Atmospheric.** Every illustration exists to produce a feeling in the room, not to catalogue what's in the scene — World System §1's founding reason for Worlds existing at all.

**Hand-crafted.** Texture, softness, and small irregularity are evidence of care, not imperfections to be corrected. World System §6 names this directly: "softly textured," "subtle imperfections."

## 3. Line Language

**Use:**

- fine lines;
- elegant proportions;
- subtle variation in weight and pressure;
- imperfect geometry;
- organic rhythm.

**Avoid:**

- thick outlines;
- technical precision;
- cartoon contours;
- icon strokes.

The line should feel drawn rather than constructed. A line drawn by hand thickens and thins, hesitates slightly, never quite repeats itself between two similar strokes — and that variation is exactly what separates an illustration from a diagram. A line built by a tool for perfect, uniform width reads as *constructed*, no matter how fine it's set: it announces a system before it shows a place.

This is the same distinction World System §6 already draws between the Circle Hero World and the interface elements around it, and the reason [Brand Book §19, Iconography](../BRAND_BOOK.md#19-iconography)'s "line-based, thin icons with consistent strokewidth" describe a *different* register than this one: an icon's job is to be recognised instantly and identically every time, so its line must be uniform. A World's job is to be felt as a place, so its line must carry the small variation a hand leaves behind. The two should never be confused for each other — an icon that looks hand-drawn has failed at being an icon; a World that looks like an icon has failed at being a World.

This quality of line does not disappear when a World is reduced. World System §5B's Activity Card Companion calls for "thin lines" and "much less detail" than the Circle Hero version — but the *character* of the line, fine and drawn rather than mechanical, carries across both. Economy changes how much is drawn. It never changes how it's drawn.

## Nature Before Geometry

Nature is irregular by default.

§3, Line Language, already asks that a line feel drawn rather than constructed. This section carries that same instinct from the line itself to the shapes a line describes: nothing in nature repeats itself exactly, and an illustration that renders it as though it did stops feeling like a place and starts feeling like a diagram.

Illustrations should reflect natural variation rather than mathematical perfection:

- trees should not have perfectly circular crowns;
- hills should not mirror each other;
- paths should gently wander rather than follow ideal curves;
- birds should vary in position, scale and posture;
- vegetation should grow in small clusters rather than evenly.

These irregularities are intentional design choices, not a lack of control. A tree crown drawn as a perfect ellipse required *less* judgment than one drawn with the small asymmetries an actual crown has — the second is harder to get right, and it is harder precisely because it has to be observed rather than assumed. This is what separates a landscape that feels observed from one that feels constructed: irregularity is evidence that someone looked at a place before drawing it.

> **Formal principle: Nature is irregular by default.**

## 4. Colour Language

Colour supports line. Colour never dominates line.

**Use:**

- a muted palette;
- restrained saturation;
- soft transitions between tones;
- generous white space within the illustration itself.

**Avoid:**

- vibrant fills;
- hard colour boundaries;
- graphic contrast.

An illustration's structure — what it is, where the eye should go, what it's a picture of — is carried by the line. Colour arrives second, to warm what the line already made legible. When colour has to do the structural work a line left undone, it tends toward the vibrant and the high-contrast, because that is the only way colour alone can separate one shape from another — and that is precisely the graphic, poster-like quality this document exists to avoid.

This follows the exact palette discipline already set for THIRTY as a whole: World System §8 names Circle Sage, Mist Sage, Warm Stone, and Cream (with approved text and neutral roles) as a World's colour base, and asks for "a narrow colour range," not an expanded one invented for illustration's sake. Playbook [Chapter 3 §6](../playbook/03-circle-design-language.md#6-color-philosophy) states the underlying reasoning this document simply applies: *"A screen that is loud everywhere has nowhere left to put emphasis."* The same is true of a single illustration — a landscape rendered entirely in saturated colour has no colour left to spend on the one moment (a low sun, a single flower) that should actually catch the eye.

The exact hex values and tokens available for this palette are defined in [DESIGN_SYSTEM.md](../DESIGN_SYSTEM.md), not here. This section governs how colour behaves once chosen — quietly, in support of line — not which colour is chosen.

## 5. Wash Language

Colour, where it appears beyond line, behaves like a quiet watercolour wash — never a flat fill, never a rendered gradient, never a glossy surface.

**A wash should:**

- suggest volume, the way light and shadow imply a form without outlining every edge of it;
- soften forms, so nothing in a THIRTY illustration reads as hard-edged or die-cut;
- create atmosphere — the mist, the depth, the softness World System §6 and §8 both ask for;
- never replace drawing. Wash sits *on top of* a scene the line has already made legible; it is not permitted to substitute for line where the drawing was left undone.

**Avoid:**

- flat fills;
- heavy gradients;
- glossy rendering.

This is the direct pictorial expression of the light World System §8 already prescribes for every World: *"diffuse morning light, golden-hour warmth, soft overcast light, light mist, quiet evening light"* — and its explicit rejection of "harsh midday contrast, dramatic cinematic lighting, neon colour, aggressive shadows." A watercolour wash and a flat vector fill can occupy the exact same silhouette and still communicate opposite things, for the same reason a progress ring and a countdown timer can share a shape and mean opposite things (Playbook [Chapter 2 §1](../playbook/02-circle-experience-system.md#1-introduction)): one is soft light settling into a form; the other is a shape that has simply been coloured in. THIRTY only wants the first.

This is also the specific quality World System §6 names when it rejects "Material-style illustrations" — flat, evenly saturated, sharply bounded fills are the visual language of interface components, not of a place worth standing in.

## 6. Landscape Language

A THIRTY landscape should feel like *one place*. Not a hill, a tree, a path, and some birds, assembled beside each other — one continuous scene those elements simply happen to be part of.

World System §6 states this directly: *"A landscape should feel like one coherent scene, not a collection of separate vector objects."* This document exists to explain what makes the difference. A collection of objects is legible one piece at a time — the eye identifies "tree," then "path," then "hill," as a list. A coherent scene is legible as a whole first, with its individual elements discovered only on a second look. The wash language of §5 is largely what does this work: soft, overlapping atmosphere between elements is what tells the eye they share the same light, the same air, the same moment — the same reason atmospheric perspective (distant forms softening and cooling in tone) reads as depth, while several equally sharp, equally saturated objects on one plane read as a diagram.

**A THIRTY landscape draws on a consistent vocabulary of elements**, established by World System §7's spatial layers and §15's Quiet Trail reference composition:

- **Sky** — soft, atmospheric, never a flat colour block; the source of the diffuse light §8 asks for.
- **Hills** — rolling and asymmetric, never a repeated, uniform curve.
- **Trees** — organic silhouettes with irregular, varied crowns; never the "perfect circular tree crown" World System §6 explicitly names as a failure mode.
- **Paths** — winding, never a straight or mechanically regular line — a path is one of the clearest opportunities for the "curved paths" and "organic rhythm" this document already asks of line (§3).
- **Birds** — small, varied in number and position (World System §15: "two or three varied birds"), a restrained sign of life rather than a flock or a pattern.
- **Vegetation** — restrained, varied, occupying the edges and foreground rather than competing with the focal element for attention.
- **Depth** — carried by the layered composition of §7 below, so the scene reads with genuine spatial distance rather than as a flat backdrop.

None of these elements is ever the subject on its own. Together, arranged with the depth §7 describes and the light §5 describes, they are what makes a World read as *one place* — which the entire purpose §1 describes.

## 7. Composition

A THIRTY illustration is composed, not filled.

**Use:**

- asymmetry;
- breathing room;
- a clear focal hierarchy;
- quiet balance;
- generous negative space.

World System §7 already requires this at the structural level — spatial layers arranged so *"the eye should be guided calmly through the scene,"* the visual equivalent of Playbook [Chapter 3 §4](../playbook/03-circle-design-language.md#4-typography)'s "one reading path per screen." This section names what makes that guidance feel calm rather than directed: asymmetry, because a perfectly centred or mirrored composition reads as designed *at* the viewer, not discovered by them; negative space, because — exactly as Playbook [Chapter 3 §5, Whitespace](../playbook/03-circle-design-language.md#5-whitespace) already states for the interface — "having room is not an invitation to use it." An illustration with space left unfilled around its focal element is not unfinished. It is the illustration equivalent of the silence Chapter 2 §6 already protects for sound and Chapter 3 §5 already protects for layout.

Illustrations should invite the eye to wander — but wander within a scene that was still deliberately composed to lead it somewhere first. A focal hierarchy and an invitation to wander are not in tension: the hierarchy is what lets the eye arrive somewhere calmly before it's free to notice anything else. A composition with no hierarchy at all does not read as inviting; it reads as unresolved.

## Observation

Illustrate the place, not the objects.

A THIRTY illustration should feel observed rather than designed — closer to a place someone remembers than a place someone assembled. The illustrator's task is to capture the feeling of a place, not to describe everything within it. A scene that enumerates its own contents has been designed; a scene that was observed can be taken in as one impression before it's read as a list.

A successful illustration should communicate:

- atmosphere;
- memory;
- calm;
- invitation.

Individual objects are never the objective. The place itself is. This is what the quiet, asymmetric arrangement described in §7, Composition, is ultimately in service of — a scene composed calmly enough that it reads as a single felt impression, not an inventory.

> **Formal principle: Illustrate the place, not the objects.**

## 8. Detail

Detail is discovered. Not announced.

A THIRTY illustration should reward a second, closer look with something a first glance didn't register — a bird half-hidden in the middle distance, a texture in the grass, a single flower along the path — without ever calling attention to that detail through size, colour, or placement. If a detail has to be made obvious to be found, it has stopped being a discovery and started being a decoration.

This is the same restraint World System §11, Personal Growth, already asks of a World's long-term evolution: growth happens, and *"the user may simply notice that something has changed"* — never through an announcement, a badge, or a pop-up. Detail within a single illustration follows the identical logic at a smaller scale: it is there for the person who looks closely, not for the person who glances once. This is also consistent with the Motion Language's parallel principle for movement (Motion Language [§2](../motion/MOTION_LANGUAGE.md#2-design-principles)): *"a user who watches closely should notice that a movement was considered — but nothing about THIRTY should require that attention to be understood."* Illustrated detail asks the same of the eye that motion asks of attention.

## 9. What We Avoid

The following are explicitly rejected, for every World, at every visual level:

- clipart;
- stock vector art;
- flat illustration;
- emoji language;
- geometric trees;
- icon composition;
- perfect symmetry;
- thick outlines;
- decorative excess.

Each of these fails for the same underlying reason, stated once here rather than separately for each: they all substitute a system's shorthand for a hand's observation. Clipart, stock vector art, and geometric trees are pre-made or mechanically regular — the opposite of the organic, imperfect quality §2 and §3 require. Flat illustration and thick outlines replace the wash of §5 and the fine line of §3 with the harder, more graphic language World System §6 already names as a failure mode ("Material-style illustrations"). Emoji language and icon composition borrow a vocabulary built for instant, uniform recognition — exactly the register §3 already distinguishes from a World's line. Perfect symmetry contradicts the asymmetry §7 requires. Decorative excess is simply detail that has stopped being discovered (§8) and started being displayed — the illustration equivalent of Playbook [Chapter 3 §2](../playbook/03-circle-design-language.md#2-visual-philosophy)'s "an element that exists only because a screen 'felt empty.'"

None of these are refused because they cannot be executed well. They are refused because, executed at any quality, they produce a *system's* illustration rather than a *place's* — and a World, by §1's own definition, has to be the second thing.

## 10. Consistency Across Worlds

Quiet Trail. Still Lake. Reading Nook. Open Meadow.

All should clearly feel illustrated by the same hand.

Different Worlds. One artistic language.

This is the illustration-level expression of a rule the World System already holds structurally: [§3](../worlds/WORLD_SYSTEM.md#3-world-structure) treats Category and Place as independently varying dimensions of one system, not as separately invented Worlds, and [§14, Continuity](../worlds/WORLD_SYSTEM.md#14-continuity-through-the-experience) requires a single World to remain recognisably itself across Home, Session, and Completion. This document extends that same continuity sideways, across Worlds rather than across one World's stages: a user moving from a Walking recommendation to a Meditation recommendation should feel like they've entered a different place drawn by the same person — never like they've opened a different app.

In practice, that means every principle in this document — the fine, hand-drawn line of §3, the muted palette and soft wash of §4–§5, the coherent-scene discipline of §6, the asymmetric, quiet composition of §7, the discovered detail of §8 — applies identically regardless of which Place is being illustrated. What changes between Worlds is *what* is drawn: a lake and reeds instead of a hill and a tree, a window and a chair instead of an open path. What never changes is *how* it is drawn.

Note that, of the four Worlds named above, only Quiet Trail (World System §15) currently has an approved World DNA and reference composition. Still Lake, Reading Nook, and Open Meadow remain placeholders per World System §16 — Open Meadow's own name is explicitly unresolved there, offered alongside "Open Room" pending a final decision. This document sets the artistic language those Worlds will be checked against once they are defined; it does not itself define them.

## 11. Review Checklist

Before any illustration ships, it should be able to answer these honestly:

- Does this illustration create atmosphere?
- Does it feel hand-crafted?
- Does it feel editorial?
- Does it invite calm?
- Does it avoid iconography?
- Does colour support line?
- Does it reward attention?
- Does it leave room to breathe?
- Could this exist in a magazine illustration?
- Does it unmistakably feel like THIRTY?

An illustration that cannot be answered well on all of these is not ready, regardless of how well it is crafted — the same standard already applied to every feature (Playbook Chapter 4 §11), every animation (Motion Language §15), and every new World (World System §19).

## 12. Document Relationships

- **The [Playbook](../playbook/README.md)** governs philosophy — why THIRTY looks, feels, and behaves the way it does.
- **[DESIGN_SYSTEM.md](../DESIGN_SYSTEM.md)** governs the interface — what a colour, spacing, radius, or type value *is*.
- **[WORLD_SYSTEM.md](../worlds/WORLD_SYSTEM.md)** governs content — what a World *is*, which Places exist, and how a World varies and grows.
- **[MOTION_LANGUAGE.md](../motion/MOTION_LANGUAGE.md)** governs movement — when THIRTY moves, and how it feels.
- **This document, the Illustration Language,** governs artistic expression — the line, colour, wash, and composition every illustrated World is drawn with.

None of those documents is modified by this one. Where a future decision in any of them would require contradicting a claim made here, that contradiction is resolved deliberately and explicitly — never by quietly overriding one document with another.
